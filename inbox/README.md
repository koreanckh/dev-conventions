# inbox — 원자료 모아두는 곳

다른 프로젝트에서 쓰던 규칙을 **아무 형식으로나** 여기 던져둔다. 형식·구조·완성도 신경 안 써도 됨.

- 러프한 메모, 규칙 목록, 실제 config 파일, 코드 스니펫, 링크 — 뭐든 OK.
- 파일 하나에 여러 규칙이 섞여 있어도 됨(분해는 import가 함).
- 어느 프로젝트에서 가져왔는지 한 줄 적어두면 출처 표기에 쓰임(선택).

다 모았으면 이 repo에서 **`/import-conventions`** 실행. 그러면:
1. inbox 전체를 읽어 주제(1주제=1규칙)로 분해하고,
2. 기존 `global/skills/*/SKILL.md`와 대조해 **겹치면 갱신 / 새 주제면 신규 생성**,
3. 이 repo 패턴(frontmatter·섹션 순서·실파일 분리·README 표)으로 정리,
4. 처리한 원자료는 `inbox/processed/<날짜>/`로 옮기고,
5. 무엇을 만들고 갱신했는지 요약해준다.

특정 파일만 처리하려면 `/import-conventions <경로>`.

## 보류 후보 (`held-*.md`)

심사는 통과했지만 **아직 적용 대상이 없어** 승격을 미룬 후보다. 파일 맨 위에 **되살릴 조건**이 적혀 있다. 조건이 충족되면 재심사 없이 그 파일의 "승격안"을 그대로 올린다 — 실패 관찰은 이미 끝났으므로 다시 따질 필요가 없다. `/import-conventions`는 `held-*`를 조건 확인 없이 처리하지 않는다.
